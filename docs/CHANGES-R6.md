# 第六轮：载具工坊——十级载具、损耗与维修、涂装

这一轮回应的是“飞机和船要有等级、会旧、能涂装，这是卖点也是损耗点”。

## 做了什么

### 1. 十级载具，四代船体
- 飞机和船各 10 级，分在四代船体里。**同一代只能原地改装**，第一代最多到 3 级；再往上要**重新造下一代**，重新涂装。

| 代 | 飞机 | 船 | 需要岛等级 | 状态 |
|---|---|---|---|---|
| 1（1–3 级） | 木架飞机 → 麻雀号 → 改装麻雀 | 筏子 → 帆筏 → 舢板 | 1 / 1 / 2 | ✅ 可玩 |
| 2（4–6 级） | 双翼货机（4 级） | 单桅帆船（4 级） | 5 | ✅ 4 级可玩，5–6 级规划中 |
| 3（7–9 级） | 游隼（原型的喷气机） | 大货船 | 7 | 游隼 7 级保留原型数值；其余规划中 |
| 4（10 级） | 飞艇 | 旗舰 | 10 | 规划中 |

- **第一架飞机、第一只筏子必须亲手造**：机库和码头里只有“亲手造”。筏子只要木材和绳子，新手不用下矿就能出海。
- 新造的体素模型：木架飞机（高单翼、裸木尾梁）、改装麻雀（翼尖油箱、双排气）、双翼货机（两层机翼、大货舱）、筏子（五根原木、捆绳、船桨）、帆筏、单桅帆船（船舱、横帆加顶帆）。每种都有带驾驶员的版本。
- 岛 5 级“港口”可以升了：目标是送货 10 次 + 任一载具改装到 3 级 + 1500 金币，开放第二代。
- 第四章的目标从“造出喷气机游隼”改成“造出第二代载具”。
- 旧存档：麻雀号算 2 级，舢板算 3 级，游隼算 7 级，损耗都是新的。
- 用不上的旧载具可以**拆掉**，拆回第一级材料的一半。整架买卖留到 10 级的玩家市场（见决定 D73）。

### 2. 载具损耗与维修
- 三项损耗，各从 100% 往下掉：
  - **引擎**（船是“舵与缆”）：按航程磨损，每公里约 1.2%（船 0.84%）。低于 60% 开始变慢，最多慢 28%；低于 25% 会“咳嗽”：冒烟、一顿、提示该修了。
  - **机身 / 船体**：被抢 −30%、被追 −8%、穿过一次暴雨 −4%、降落太烂 −5%；高等级船体更结实（除以坚固系数）。低于 60% 货舱变小，最多少 45%。
  - **涂装**：每趟 −3%，暴雨和被抢再多掉；掉色让模型的颜色往灰里褪（看得见）。
- 降落后如果有一项该修了，会提示一句。
- **修理**：在家的机库 / 码头用材料 + 少量金币（引擎用铜锭或铁锭，船用绳子；船体用木板，坏得多再加帆布）；在外岛只收金币，贵一倍。改装升级时顺带把引擎和船体修好。

### 3. 涂装
- 机库 / 码头的卡片上点“涂装”：机身色、点缀色（条纹、尾翼）、帆布 / 蒙布色、条纹（无 / 单条 / 双条 / 格纹），以及帆面（或机翼）上 12 × 8 的像素图案。左边有实时预览。
- 8 种颜料就是 8 种颜色，在工作台新的“颜料”页做（每次做两份）：红（野花）、黄（麦子 + 野花）、蓝（铜矿 + 贝壳）、绿（纤维）、白（贝壳）、黑（煤）、粉（草莓 + 贝壳）、银（珍珠）。
- 每用一种**新**颜色花一份颜料；漆掉到 70% 以下重涂要全部重付；只是补漆加一份白颜料。涂完涂装损耗回到 100%。
- 每辆载具按自己的涂装和褪色程度生成自己的模型（`veh_<id>`），停在机库、码头、起飞、飞行时都是它。
- **联机**：你最得意的那辆（有涂装的优先，其次等级最高）会写进岛卡；别的玩家路上遇到的“过客”有七成是真玩家的载具，涂装是他们的，喊话也用他们的岛名。读进来的涂装逐项检查，坏数据一律丢掉。

### 4. 工具会坏（推翻 D28）
- 所有工具都会坏：石斧 / 石镐 40 次、铜 120 次、铁 300 次、钓竿 60、捕虫网 60、鱼枪 80。每砍一下、挖一下、甩一竿、挥一网、开一枪算一次。
- 快坏时（剩 12%）提醒一次；坏了就从背包里消失，带一阵碎屑和提示。
- 工作台“工具”页底下多了“修工具”：石器用树枝 + 卵石，铜器用铜锭，铁器用铁锭，钓竿用树枝 + 绳子，网用纤维，鱼枪用绳子 + 铜锭。修好是全新的。
- 快捷栏和背包格子底部有一条耐久条，悬停 / 长按看“耐久 x / y”。

## 没做的 / 留到后面
- 第二代的 5–6 级、第三代的大货船、第四代：数据里占了位（“规划中”），模型和数值还没定。
- 战斗之后的“大修”目前就是船体损耗多掉（被抢 −30%）；以后有真正的空战 / 海战再细分部位。
- 工具没有分“锋利度”，只有次数。
- 玩家之间整架买卖载具（和卖设计稿）：10 级的交易所再做。
