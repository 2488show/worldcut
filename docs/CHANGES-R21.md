# 第 21 轮：整块铲平、按体力睡觉、货单分档、多座熔炉

用户提了四件事，讨论后说"加数量，然后一次可以操作多个同时进行""按你的想法来"。

## 1. 铲平整块占地（D146）
- 摆熔炉、餐厅、牧场、小店、货运站、灯塔、交易所时，如果只是地不平，提示条出现"铲平这块（n 下）"：人走过去，按面积铲 n 下（每下约一块 11×11），整块铲平后直接放下。
- 体力和铲子耐久按下数扣；体力不够会先说要多少。
- 地上的小石子、树枝跟着土一起收起来。铲平的地记在存档里（矩形），重开游戏还是平的。
- 挡着的东西现在说清楚："有橡树挡着：先砍掉"，不再笼统说"放不下"。
- 平时拿铲子点地不变（一小块、挖饵）。

## 2. 睡觉按体力（D147）
- 什么时候都能上床。白天多一个"睡个午觉"：两小时，体力 +35，不跳天。
- 去掉凌晨 2 点必晕。过了半夜体力每秒掉 0.12（到天亮约 36），剩 15 时提醒，掉光就地睡着（第二天六成体力、被扶回家的费用照旧）。在飞机或船上不掉。

## 3. 货单分三档（D148）
- 小单（岛 1–3 级）：原料（木板、石头、浆果、鱼、胡萝卜、纤维、小麦、贝壳、煤），只出安全航线，量在第一架飞机一趟之内。最近那座岛的第一单固定是它想要的原料。
- 中单（4–6 级）：七成是加工品（铜锭、铁锭、绳子、布、菜、小家具），三成小单。
- 大单（7–10 级）：六成是金锭、水晶、金枪鱼、月光鱼、路灯、水晶灯、海鲜大餐等，量更大。
- 各岛先要自己愿望单上同档的东西，没有就从这一档里挑。
- 布告板每单标"小单 / 中单 / 大单"，并写"用木架飞机（货舱 6）一趟送完"或"要货舱 n 格以上的载具"。
- 市场改用自己的随机数，不再和航行中的海盗、风共用一串（之前改货单会让飞行测试里的追击变样）。
- 没做：一单要两三种货。

## 4. 多座熔炉同时烧（D149）
- 熔炉数量：岛 1–3 级 1 座，4 级起 2 座，7 级起 3 座。工作台做套件，照常摆。
- 放进去的每一炉分到最快空出来的那座，几座同时烧；每座最多排 8 炉。熔炉窗口分座显示进度，每座头上各有"冶炼中"。
- 工作台没有加数量：做一件只要 0.8 秒，不是瓶颈；改为加了"做 10"。
