# 第 18 轮

用户提的四件事，先讨论再动手，按"坐下 bug + 视角 → 菜地 → 钓鱼"的顺序做。

## 1. 屋里坐下后动不了（修好）
- 原因：站起来时只往前挪 6 格。椅子朝着桌子，人就站进了桌子里，卡死。
- 现在 `game.standUp()` 从面朝方向开始，一圈一圈找最近的空地（格子和四邻都不是实心、不是水）。

## 2. 视角控制收进设置（D140）
- 画面上的三个视角按钮删掉。
- 设置窗口里加"视角"一行：换成俯视 / 换成斜视、左转、右转、拉远 / 拉近。
- 手机：两指捏合拉远近，两指拧转镜头（stage.ts）。键盘照旧：空格、Q / E、滚轮。

## 3. 菜地重做（D141）
- 一整片地：4 列，一排排往下长，格子挨着格子，四周有木边。岛 2 级 4 块，之后 8 / 12 / 16 / 20 / 24（3 / 4 / 6 / 8 / 10 级）。
- 每块地从"荒地"开始：清掉杂草（得草纤维）→ 耕地 → 播种。照料（浇水 +1 / 天，施肥 +2）攒到 3 是"好地"，到 8 是"肥地"。肥地收成多一份。
- 浇水：要水壶（木板 1 + 铜锭 1；改版时送一把）。一次浇一整排。只有湿着的时间才算生长；下雨天全部地自动湿到当天结束；不浇水当天不长。
- 施肥：这一茬快四分之一，收成多一份。
- 肥料从堆肥箱来（菜地旁边）：把杂草、草纤维、烂掉的东西、鱼、多余的作物丢进去，每 4 点第二天早上变 1 袋肥料。有牧场时宠物每天再添一点。
- 旧存档的菜畦和里面的种子会搬到新菜地里。
- 取舍：离线生长取消了（要浇水才长）。

## 4. 钓鱼（D142）
- 开船出海钓鱼：船在海上、带着钓竿时出现"抛锚钓鱼"。抛锚后船停住（风和海流也推不动），"抛竿"往船侧前方甩，"起锚"继续走。靠岸会自动起锚。
- 海上有自己的鱼：飞鱼、鲭鱼、鲣鱼、金枪鱼、月光鱼（夜里）、旗鱼。离所有岛都远的深水里，大鱼的比例从约 20% 提到约 43%，鱼的个头也更容易偏大。新增三种鱼：飞鱼、鲣鱼、旗鱼（150–320 cm），鱼图鉴 14 种。
- 鱼筐：草纤维 6 + 木棍 3。带着它，钓上来的鱼先进筐（20 条，不占背包），每条记着长度。快捷栏上方有鱼筐按钮，打开能看每条鱼多长、一键收好。
- 晒鱼架降价：木板 3 + 绳 1（原来棕榈木 4 + 绳 2 + 鲭鱼 2），价值 70 → 30。鱼标本 40 → 20。晒鱼架和奖杯旁边现在有牌子，写着你钓过最大的鱼：鱼名、多少厘米、第几天。
- 声音：进筐声、钓到大鱼的三连音；破纪录时飘字"新纪录！"。
- 音乐：新的"钓鱼"场景（慢、音少、海浪垫底），竿在水里或抛锚时播放。
