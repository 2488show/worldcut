# 第 23 轮 · 语言框架（中英双语第一步）

## 做了什么

- **改名**：游戏名改为《云岭航行》，英文 Worldcut。改了标题画面、关于页、网页标题、相册导出文件名、README、package.json。游戏世界里的"云屿 95"电脑、"云屿邮局"、"云屿日报"、"云屿航运"是群岛的地名，保留不改。
- **`$t()` 语言函数**（`src/i18n/index.ts`）：中文原句当键。`$t('还差 {0} 金币', n)` 在中文下原样返回，在英文下查 `src/i18n/en.ts`；查不到就退回中文，所以缺翻译不会让游戏出错。
  - `{0} {1}…` 是参数，英文句子可以随意调换位置。
  - `{0|plank|planks}` 按数字选单复数。
  - `SEP()` 返回列表分隔符（中文"、"，英文", "），新代码优先用它。
- **全量套用**：用语法树脚本（`tools/i18n-wrap.cjs`，一次性）把 53 个文件里的中文显示文字都套进了 `$t()`，包括普通字符串、模板字符串、界面文字和属性。共 2200 句。
- **语言开关**：
  - 默认跟随浏览器语言（中文浏览器进中文，其他进英文）。
  - 标题画面和设置里都有"中文 | English"，切换后记住选择，页面重新加载，存档不丢。
  - 地址栏加 `?lang=en` / `?lang=zh` 可以强制指定语言，给截图和宣传片用。
- **`npm run i18n`**：扫代码，更新 `en.ts`。
  - 新句子补成空行，已删掉的句子移除，按文件分组。
  - 顺带列出没套 `$t` 的中文。
  - 加 `-- --check` 时，有缺翻译或漏网中文就报错，发布前用。
- **手工改的四处**：这几处原来拿中文字面做判断，换成了不依赖文字的写法。
  - 做饭提示的红字：改用 `acts.bad` 标记。
  - 访客"点一下和……说话"的提示：记下原句再比对。
  - 访客点评家里缺什么：`cosiness()` 现在分别返回房间名和缺的家具（`gaps`）。
  - 被窝里的天气句：用英文 ID 查表。

## 已知限制

- **英文还没翻**：目前 `en.ts` 全是空行，英文模式显示的仍是中文。下一步翻译。
- **已存下的文字不随语言变**：信箱里的旧信、旧新闻、留言簿，换语言后保持写下时的语言，新生成的会用新语言。
- **英文排版没核**：英文比中文长，按钮和窗口会不会撑破，要等翻译完逐页截图核。
- **其他**：
  - 岛民说话的"语音"按字数生成，英文按字母数，可能偏长，翻译后要听一下。
  - 像素字体的英文字形还没确认好不好看。

## 测试

- vitest 147 个全过，新加 `tests/i18n.test.ts`，其中一条检查每句英文的 `{0}{1}` 和中文一致。
- 桌面和手机的端到端测试全过。
- 另跑了一个浏览器检查：德语浏览器默认进英文，切换后页面重载，金币保留。
- 测试耗时和改动前持平（slice 67 秒对 70 秒）。

# 第 23 轮（续）· 英文翻译

## 做了什么

- **全量翻译**：`src/i18n/en.ts` 2203 句全部有英文。分 12 批按文件翻，物品、鱼、岛主对话、信件、新闻按英文的说法写，不逐字直译。
- **术语表**（之后加新内容照这个译）：

  | 中文 | 英文 | 中文 | 英文 |
  |---|---|---|---|
  | 金币 | coins | 体力 / 饱腹 | Energy / Fullness |
  | 魅力 / 温馨度 | Charm / Coziness | 布告板 / 货单 | notice board / order |
  | 货舱 | hold | 背包 / 仓库 / 快捷栏 | bag / storage / hotbar |
  | 空盗 / 海盗 | sky pirates / pirates | 岛主 | islander |
  | 好感 | friendship | 图鉴 | Field Guide |
  | 航海日志 | Logbook | 岛务手账 | Island Planner |
  | 云屿 | Cloud Isles（云屿 95 → Cloud Isles 95） | 机库 / 码头 | hangar / dock |
  | 涂装 | paint job | 套件 | kit |

- **人名和地名**：
  - 人名：阿澈 → Che，老周 → Old Zhou，守灯人 → The Keeper；Lena、Mio 不变。
  - 岛名：石峰岛 → Stone Peak，雾松岛 → Misty Pine，珊瑚环礁 → Coral Atoll，赤砂岛 → Red Sand Isle，彼岸 → Farshore，无人礁 → Lonely Reef。
- **英文单复数**：常见的计数词用 `{0} {0|order|orders}` 的写法，共 66 处，例如 "1 order / 3 orders"。
- **为英文改了代码**，都是中文写法英文拼不起来的地方：
  - 用量词拼的两句拆成整句："已经有一艘船 / 一架飞机"、"亲手造一艘 / 一架"。
  - 设置里镜头的"拉近 / 拉远"改成"镜头拉近 / 镜头拉远"，和钓鱼进度条上的"拉近"分开翻。
  - 炒股新闻、周报、传闻里"公司名 + 事件"的拼接改用 `$t`，英文显示成 "Dune Spice Co.: A big customer walked away"。
  - 工坊标签"第二代 + 飞机"改成一整句（"Generation 2 plane"）。
  - 左上角的等级角标，英文显示 "Lv 3"，中文仍是 "3 级"。
  - 钓到大鱼的标题加了空格（"Caught Tuna!"）。"砍 / 挖 / 采"在英文里只出现在句中，所以小写。
- **英文排版**：
  - 标题和副标题的字距在英文下调小。
  - 稀有度标签和名字之间留了空隙。
  - 信件附件那一行允许换行。
  - 布告板"要货舱 N 格以上"缩短成 "Needs hold N+"。
- **像素字体**：Fusion Pixel 的英文字母显示正常，不用换字体。
- **测试**：
  - 端到端测试固定用 `?lang=zh`，因为测试浏览器是英文环境，现在会自动进英文。
  - 占位符一致性检查改为比较占位符的集合，单复数写法会让 `{0}` 出现两次。

## 已核过的英文界面

- 标题画面、捏人、HUD
- 布告板、工作台、航海日志、岛务手账、设置
- 信箱、背包、机库、股市

没有截到的：

## 还要注意

- 英文是我一个人译的，没有母语者审过。上线前最好找英语母语的朋友玩一遍，重点看对话和信件的语气。
- 有些拼接句在英文里是"名词 + 冒号"的写法，比如 "Wind shift: Strong tailwind"，读得懂但不够自然。
- 岛民说话的"语音"在英文下按字母数生成，可能偏长，要听一下。
