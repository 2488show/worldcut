# 第十三轮改动：书桌上的旧电脑，钓具箱和鱼饵

用户给了两张参考图：一台放在书桌上、能玩扫雷的复古电脑，一个打开的钓具箱。先讨论，后动手。用户确认了四件事：
- 电脑做成整个"桌面"，把股市、信箱、天气、图鉴、相册都收进去；
- 加一个能赚点小钱的扫雷；
- 加鱼饵；
- 电脑放在会客区的书桌上，不再保留炒股机。

## 1. 书桌上的旧电脑

- 点书桌上的电脑，画面切换成全屏的书桌场景：机箱、CRT 显示器、键盘、绿色台灯、鼠标垫，台灯的暖光落在木头桌面上。这些都是手绘像素，放大时保持硬边。
- 开机先显示"云屿 95"的启动画面，然后进桌面。桌面上 7 个像素图标：股市、信箱（有未读信时带红点）、天气、鱼类图鉴、相册、扫雷、回收站。
- 窗口是 Win95 风格，一次只开一个。股市窗口是深色屏幕配黄色价格，保留红涨绿跌。
- 任务栏有"开始"菜单（可以关机）、当前窗口的标签，右下角的时钟显示游戏时间。屏幕上加了扫描线和暗角。
- 天气窗口显示今天起的 5 天预报。
- 屏幕大小：
  - 横屏时镜头推近，让屏幕足够大、看得清字。
  - 手机竖屏时，屏幕占据大半个画面，四周画一圈显示器外壳，下面露出键盘、台灯和鼠标。
- 原来的各个面板没有重写：放进电脑窗口时，它们会自动去掉自己的纸质外框，只显示内容。

## 2. 扫雷

- 三档难度：初级 9×9、10 个雷；中级 12×12、24 个雷；高级 16×14、40 个雷。
- 第一下点开的格子和它周围一圈一定没有雷。
- 点一个数字格，如果它周围的旗子数已经插够，会自动点开剩下的格子。
- 插旗：电脑上用右键，手机上长按，或者先点⚑切换到插旗模式。
- 顶部是红色 LED 的剩余雷数和计时，中间的笑脸按钮可以重开，还有排行榜（每档难度的最快用时）。
- 结算：每天前 3 局胜利有金币（初级 15、中级 40、高级 90），之后只记成绩不给钱。这样它是消遣，不会比干活还划算。

## 3. 钓具箱和鱼饵

- 拿着鱼竿时，快捷栏旁边会出现一个钓具箱按钮，上面显示现在挂的是什么饵；电脑上按 Tab 也能打开。
- 箱子的样子：盖子里插着拟饵；托盘的格子里放活饵，右下角标着数量；鱼竿绑在侧面。点一格会弹出说明：名字、有几个，以及一排它招来的鱼的小图标（钓到过的是彩色，没钓到过的只是剪影；夜光饵旁边有个月亮）。点"用这个"挂上，点"取下"摘掉。
- 鱼饵（用一个少一个，鱼咬钩时就被吃掉）：
  - **蚯蚓**：用铲子在平的草地上挖。什么鱼都吃，咬钩最快。
  - **小虾**：用铲子在沙滩上挖。鲷鱼最爱。
  - **面团饵**：工作台上用 1 份小麦做 4 个。专招沙丁鱼。
  - **鱿鱼块**：工作台上用 1 条鱿鱼做 4 块。招金枪鱼和月亮鱼。
- 拟饵（用不坏，在工作台做）：
  - **亮片**：招鲭鱼。
  - **软虫**：招鲷鱼和沙丁鱼。
  - **夜光饵**：只在夜里有用，月亮鱼只认它。
- 挖饵：铲子点在没什么可铲平的草地或沙地上，就改成挖饵，挖两下，四次里有三次能挖到 1–2 个。这在任何岛上都能挖。
- **钓鱼本身的手感没变**，还是第十轮那套。鱼饵只决定来的是哪种鱼、要等多久。

## 4. 炒股机 → 电脑

- 新存档的会客区书桌上直接放着电脑。
- 旧存档里的炒股机会变成电脑，放到书桌上；书桌上放不下，或者有多台，就进家具箱。家具箱里的炒股机也一样换成电脑。
- 炒股机不能再在工作台做了。电脑的配方是 2 木板、3 铜锭、1 水晶。

## 补丁（2026-11-18）：旧存档打不开

- **现象**：第十一轮或更早的存档，用第十三轮的版本打开时直接卡住，标题画面出不来。
- **原因**：读档时要把旧房子里的家具搬进第十二轮的新房间。搬的时候，摆放检查会去看"玩家是不是正站在那儿"，但这时世界还在生成，玩家还没出现，程序就报错了。
- **修复**：
  - 只有玩家在屋里时才做这项检查。
  - 房子搭建外面加了一层保护：就算房子出了任何问题，游戏也照样能打开。
- **验证**：
  - 用第十、十一、十二轮的版本各自存档，再用新版本"继续"，三份都能正常进岛。
  - 新增一个测试：用旧格式的存档开新游戏，家具一件不少，炒股机也换成了电脑。
