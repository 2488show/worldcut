# 第 20 轮：餐厅能吃饭；股市有新闻、周走势、假消息和传闻

用户问：为什么餐厅只能做饭；炒股能不能借鉴同类游戏。讨论后定了：餐厅按我的想法改；电脑里加新闻系统、访客传闻、每周走势型、假新闻。

## 餐厅和灶台（D144）
- 窗口分两页："用餐"列出现成的菜，点"坐下吃"就走到桌边坐下吃；"后厨"做菜。餐厅有现成菜时默认打开"用餐"。
- 做好一道菜后，结果那一行旁边出现"现在吃"。
- 屋里的灶台同样两页，吃的时候走到餐桌边。

## 股市（D145）
- **每周走势型**：每家公司每周暗中是四种之一：横盘、缓涨、中途暴涨（周中某一天猛涨）、阴跌。周一日报回顾上周各家是什么型，玩家可以从图上学着认。
- **新闻来源**：
  - 云屿日报：都是真的（公司新闻、天气影响、更正、周一回顾）。
  - 气象台：提前一天预报暴雨、大雪、大雾和受影响的公司，真的。
  - 海风小报：约 45% 的日子出一条，差不多一半是编的。消息一出价格先跳；假的当天会跌回去，隔天日报更正，原文划掉。
  - 股评专栏：每周三猜一家公司这周的走势，三次对两次。
  - 听来的：请客人吃饭，席间客人会透露一句某家公司这周或下周的走势；交情越深越准（0 好感约 55%，满好感 90%）。
- 电脑桌面加"新闻"程序：按天列出，标来源和"可信 / 真假难辨 / 看交情"，可只看日报和气象台，或只看小报、专栏和传闻。
- 股市窗口的新闻栏标出来源。

## 没做
- 持仓上限、分红：用户这轮没选。
- 来客平时坐在餐厅吃饭（不请客时）：没做。
