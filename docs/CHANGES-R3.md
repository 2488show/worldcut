# 第三轮改动清单：从切片到完整的游戏（2026-11-17）

这一轮的任务只有一句话：“做成一款完整的游戏”。我对“完整”的定义是四件事，按这个顺序做的；每一段做完都能完整运行。

状态：**[完成]** 做完并有自动测试 · **[待你验证]** 代码和模拟测试都有，但真实环境只有你能试 · **[未做]** 没做，原因写在后面。

## 1. 有头有尾

- **[完成] 标题画面**：岛在后面，名字在前面。有存档显示“继续”（岛名、第几章、岛的等级、金币），没有则“开始”。新游戏要点两次才生效。
- **[完成] 菜单**（右上角 ≡）：音乐、音效各自的音量，静音，给岛起名，联机状态，操作说明，回到标题，重新开始。开发者捷径收进了菜单最下面。
- **[完成] 主线五章**：原来的十步指引是第一章“登岛”。之后四章各有 3–4 个目标，全部读存档判断，不按顺序做也不会卡住。每章完成有全屏演出、金币和一件家具。
  - 第二章 站稳脚跟：捕 3 条鱼、矿洞到 3 层、摆 3 件家具、送 3 单。
  - 第三章 远航：下潜一次、升级成大岛、四座邻岛都去过、在 ☠ 航线上送到一单。
  - 第四章 群峰：铁镐、矿洞 7 层、造出游隼、魅力 40。
  - 第五章 海的那一边：和四位岛主成为老朋友、拼出远海海图、飞到海图上标的地方。
- **[完成] 岛主好感度**：给一位岛主送到 1 / 3 / 5 单，分别成为“认识了 / 熟人 / 老朋友”。前两级送特产或家具，第三级送一片海图残片，每人有三句自己的话。
- **[完成] 结局**：四片残片在工作台拼成远海海图，海图上多出一座之前看不见、也降落不了的岛——彼岸。那里有全游戏最高的灯塔和守灯人。第一次降落触发结局面板（一段话、你的统计），带回“守灯人的提灯”。之后游戏照常继续，彼岸变成一条卖月光石的终局航线。
- **[完成] 航海日志**（右上角“志”）：目标、岛与岛主（好感度、距离、危险、出什么缺什么）、图鉴（62 样东西按六类，没见过的是问号，每类集齐有金币）。

## 2. 真的能和别人一起玩

- **[待你验证] 联机**：页面声明了共享数据库。异步，不需要同时在线。
  - **朋友的岛在你的海图上**：最多两座，落在两块固定的空海域。它由对方的种子和等级长出来，地形、村子位置和对方自己看到的一样；对方摆的家具也在。
  - **互相下单送货**：布告板多了“向玩家求购”。金币挂单时押上；别的玩家接单、装货、飞到你岛上降落，对方当场拿到钱；你下次上线，货飞进背包。没送到的部分退款。同一张单两个人同时抢，只有一个人抢得到。
  - **云存档**：存档每两分钟（有变化才）同步一次，换设备打开会用较新的那份。
  - **只读**：对方的分享权限如果是“查看”，能看到别人的岛和订单，但不能挂单、没有云存档；菜单里会写明。
  - **不在 Claude 里打开**（本地文件、开发服务器）就是单机，和以前一样。
- **[完成] 两人对玩的自动测试**：两局无头游戏共用一个内存里的假数据库，走完“互相看见 → 挂单 → 接单 → 飞过去 → 收钱 → 对方收货 → 云存档下载”全程，另有只读席位和脏数据的测试。
- **我没法验证的**：真实数据库那 80 行适配代码（`src/ui/cloud.ts`）只在 Claude 的页面里才有东西可连。它出任何错都会退回单机，不会让游戏打不开。

## 3. 补齐上一轮的简化

- **[完成] 烟幕弹**：煤 2 + 帆布 1。被盯上时按 G（或点按钮）：海盗瞎飞 5 秒、咬合清零、耐心少 8 秒。满载直飞，两颗能保住全部货。
- **[完成] 雾**：旅程上的天气现在有雨（慢）和雾（藏身）两种。在雾里待 2.5 秒，海盗就跟丢了。
- **[完成] 家具旋转**：摆放时有“转向”按钮，四个朝向。
- **[完成] 昼夜**：20 分钟一天，黄昏、短夜、清晨。夜里月光鱼上钩的机会是白天的 6 倍。
- **[完成] 种植**：砍橡树掉橡果，采浆果丛和亚麻丛掉苗和籽。在小屋里“种下”，几分钟后长成和野生一样的树或灌木，可以反复收。最多 16 棵。
- **[未做] 更多天气种类、可选的全手动落地、护航、室内家具**：价值排在联机和主线之后，没排到。

## 4. 收尾

- **[完成] 旧存档迁移**：第二轮的存档（v2）打开时自动升到 v3，不丢东西。
- **[完成] 存档不会越玩越大**：已完成的订单会被清掉；云存档超过 230 KB 就不上传。
- **[完成] 修掉的问题**：好感度升级的横幅用了一个不存在的图标名，会让页面报错——端到端测试抓到的，已修，并加了“每样东西都有图标”的测试。
