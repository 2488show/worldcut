# 第十四轮改动：真窗户、床边机位，以及一个藏了两轮的镜头 bug

用户反馈：窗户一闪一闪、看不到室外；卧室没窗户、睡觉的机位不对（附了一张参考图）；并问房屋升级是怎么设计的。

## 1. 屋里镜头方向的 bug（第十二轮留下的）

- 房子会朝四个方向之一。门朝东或朝西的岛上，进屋后镜头是从**后墙外面**往里看的，不是从门口那侧。
- 原因：镜头的朝向和家具的朝向正负号约定不同，我直接用了同一个角度。门朝南、朝北时碰巧是对的，所以之前的截图没发现。
- 这很可能就是"卧室没窗户、窗户闪"的直接原因：从后面看，窗户贴在墙里，和墙面抢着画。
- 已修，并加了测试：四个朝向都检查镜头是从门口看向后墙。

## 2. 窗户是墙上真正的开口

- 外墙在窗户的位置只砌到窗台，上面是木窗框和过梁。从屋里看出去就是真实的岛：树、海、天、别的建筑。
- 原来"画在玻璃上的风景"整套删掉了，闪烁也随之消失（两帧静止画面对比，屋内不再有变化的像素）。
- 屋里时，雨和雪只画在屋外：越过墙头和透过窗户能看到雨丝，屋里的地板和家具上没有。
- 从屋外看，窗户是关着的玻璃窗，带花箱，晚上会亮。
- 外墙加高到 17，让窗户有 9 格高。窗户共 4 扇：卧室一扇宽的（19 格），厨房、客厅、会客区各一扇。
- 挂在墙上的东西不能挡住窗口；旧存档里正好挂在新窗口位置的，会进家具箱。

## 3. 卧室和睡觉的机位

- 床改成贴着后墙横放，头朝侧墙，正上方就是那扇宽窗。床头有床头柜和台灯，床前有圆地毯，衣柜和落地灯在床尾一侧。
- 躺下后的镜头：在睡的人右手侧、略高于被子的位置，横着看过床，对着窗。墙头正好在画面顶端，地平线落在窗户里。
- 为了让镜头能退后一点，卧室和客厅之间的那段墙在躺下时会暂时放平，起身后恢复。
- 引擎加了三样东西：近景放大、允许镜头低于周围的墙、"不下雨的区域"。
- 床如果被玩家挪到别处，镜头会自动选床的右侧；右侧没空间就选左侧。
- 手机竖屏：缩小到整张床都能放进画面。
- 起床后站的位置改成床靠房间的一侧（原来在旋转过的房子里可能站进墙里）。
- 旧存档：床、衣柜、落地灯如果还在原位，会搬到新位置；床头柜、台灯、圆地毯是送的。

## 4. 顺手修的

- 信箱在门朝东、西的岛上可能被放进屋里。现在按门的朝向找位置，并且不会落在房子范围内。

## 已知问题

- 近景下体素很大，家具看起来是一块一块的，和参考图的精细像素画有差距。这是引擎的画法决定的。
- 床头柜离镜头近，会占掉画面左下角一块。
- 窗外是什么取决于房子后面是什么：有的岛是海，有的岛是树或机库。
- 屋里视角下，房子前面的大树可能挡住屋内一角。
