# 第七轮：回家——室内、体力与饱腹、统一的摆放

这一轮回应的是：显示 bug；摆东西太麻烦（熔炉在工作台里放、种子要自己找空地）；要一把能造出空地的工具；摆放时显示能不能放；房子要有室内（卧室、客厅、会客、卫生间带淋浴），晚上要回去睡；加上疲劳和饥饿（参照星露谷物语）；以及我自己也要提想法。

## 修了什么
- **船上的人是一摞彩条**：载具模型画的时候没有画侧面，从船尾低处看，人的每一层体素就成了一条一条的。现在载具都按“带侧面”的方式画；离得很近时（船就在镜头前），每个体素画成实心的方块，不再是一排点。骑手也重做了：有肩膀、手臂，后脑勺是头发（从船后看过去看到的是头发，不是脸）。
- **菜地显示不对**：菜地模型只有一层、还沉在地面下 0.6，所以只看得到轮廓线。现在是一圈木框的抬高苗床，作物也都按带侧面的方式画。

## 统一的摆放
- 所有能摆的东西用同一套：**家具（屋外和屋里）、树种、熔炉**。拿起来（快捷栏选中，或背包里点“摆出去”），地上就出现一个半透明的它：**绿色能放，红色不能**，并在横幅里说出原因（“地不平：用铲子铲平”“有东西挡着”“会挡住门口”……）。
- 鼠标：跟着指针走，点一下放下。手机：点一下把它挪过去，再点一下同一处（或按“放这里”）放下。能转向的会显示“转向”。
- 熔炉不再在工作台里放：做出熔炉套件后，像其他东西一样拿在手上摆（横幅里还有“推荐位置”）。
- 颜色按惯例用**绿 = 能放、红 = 不能放**；想换成你说的“红 = 能放、蓝 = 不能放”，改 `aimAt` 里的一行颜色即可（见决定 D79）。

## 铲子：造出空地
- 新工具 **铲子**（工作台“工具”：树枝 2、卵石 2）。拿在手上，地上会出现一个 11×11 的框（绿 / 红）。点一下：小人走过去铲三下，**把这一块铲平**，顺手把上面的树枝、卵石、亚麻、花、贝壳收进背包。
- 铲不了的：挨着水、路面跑道码头、坡太陡（高差超过 9）、有树或石头挡着（先砍掉 / 敲掉）。
- 铲平的地会记在存档里，岛升级重建地形后还会再铲平一次。铲子会磨损（60 次），每铲一下耗 4 点体力。

## 房子的室内
- 点小屋就**进屋**。屋子像矿洞一样搭在一片空海上，用同一个渲染器画，所以光影、视角和岛上一致。前墙只是一道矮窗台（像娃娃屋），斜视角下能看进每个房间。
- 五个空间：后排 **卧室**（床、衣柜、落地灯、岛务桌）、**卫生间**（马桶、洗手台、淋浴间）、**厨房**（橱柜、灶台、冰箱、餐桌和两把椅子）；前排 **客厅**（电视、地毯、茶几、沙发、书架、盆栽）和用半堵墙隔开的 **会客区**（两把椅子、盆栽）。每间有自己的地板和墙纸。
- 家具都能用：床睡觉，淋浴 / 浴缸每天一次回体力，灶台和橱柜做饭，冰箱连着仓库，岛务桌（原来小屋的面板：等级、宠物、炸岛重开），书架打开航海日志，电视播天气预报，沙发和椅子坐下慢慢回体力（最多回到六成），马桶和洗手台……就是马桶和洗手台。
- **装修**：屋里横幅点“装修”，再点任何一件家具，它回到背包并立刻进入摆放（绿 / 红），放到别处。家具不能压墙、不能挡门口和大门、不能叠在一起（地毯上可以放东西）。
- 新家具 12 种可以在工作台做：椅子、茶几、书架、盆栽、地毯、落地灯、沙发、餐桌、衣柜、浴缸、电视柜（另有初始套装里的床、马桶、洗手台、淋浴、灶台、冰箱、橱柜、岛务桌）。
- **温馨度**（我加的）：家具魅力之和，每间屋配齐该有的（例如卫生间：马桶、洗手台、淋浴）再加 10。在岛务桌上看。

## 体力、饱腹、时钟和一天的结束（参照星露谷物语）
- 左上角多了 **时钟（第几天 · 几点）**、**体力条**、**饱腹条**。
- **体力**（满 100）：砍树 / 挖矿每下 2，铲地 4，甩竿 3，鱼枪 2，挥网 1，徒手捡 1。低于 20 走路变慢；不够了就**干不动**（提示去吃东西或睡觉）。
- **饱腹**（满 100）：随时间下降，约三分之二天从满到空；干活也会饿一点。低于 20 时**干活耗的体力多一半**；饿到 0，体力最多只剩七成。
- **吃**：快捷栏选中食物，屏幕下方出现“吃 ×× ”按钮；背包里的食物提示也有“吃一个”。生的：浆果、胡萝卜、草莓、南瓜、鸡蛋；做熟的（灶台）：煎蛋、烤鱼、面包、浆果果酱、胡萝卜汤、鲜鱼汤、南瓜浓汤、草莓派、海鲜大餐——做熟的比生吃顶饿得多。
- **睡觉**：18 点以后点床就睡（太早睡不着；但累得只剩不到 25 时随时能睡）。一觉到第二天早上 6 点，体力回满（过了半夜才睡只回八成五），夜里会饿一些。
- **熬到凌晨 2 点**：原地累倒，第二天在家醒来，只回六成体力，被收走 5% 金币（最多 200）。在别的岛上累倒，就在那个岛主家借住一晚。
- **一天的小结**（我加的）：睡觉时弹出——今天的净收入、送达订单、采集、收菜、捉到的小动物、做了几顿饭，以及今天的天气。
- **天气预报**（我加的）：每个岛每天有固定的“多雨 / 晴”，电视上能看到明天的；多雨的日子阵雨多得多（庄稼长得快、蜗牛青蛙出来），晴天适合出海。
