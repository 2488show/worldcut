# 第四轮：背包、手上的工具、细节（2026-11-17）

按你的试玩反馈做的，加上我自己重玩一遍时看到的问题。

## 你点名的三件事

- **[完成] 快捷栏 + 背包**
  - 屏幕下方固定 **8 格快捷栏**，不再是一条拉不完的横栏。右边是背包按钮，显示“已用 / 总格数”，满了会变红闪。
  - 没有背包时，身上只有这 8 格。在工作台“装备”里做背包，每个多一排 8 格：草编背包（纤维 8、树枝 4）→ 帆布背包（帆布 4、绳索 3）→ 远航背包（帆布 6、铁锭 2、贝壳 4），最多 32 格。新背包替换旧的。
  - **一格放多少**：材料和加工品 30，鱼 10，工具、装备、家具 1，烟幕弹 5。
  - **背包面板**（点按钮或按 B）：全部格子，没解锁的那排是虚线。点一格再点另一格就交换；点一样东西看说明，可以“放到快捷栏”或“拿在手上”。
  - **仓库变成真的仓库**：以前只是显示背包。现在点身上的格子存进去，点仓库里的东西拿一组出来，有“全部存进去（工具除外）”。在家里，工作台、熔炉、装货、升级都直接用仓库里的东西，不用来回搬。
  - **满了会怎样**：采集、钓鱼、挖矿之前先检查，装不下就不让开始，并提示“去仓库放东西，或做个背包”。任务奖励、送来的礼物、熔炉在你不在时炼好的锭，直接放进仓库。万一采集的额外掉落装不下，多出来的送回仓库并提示。
  - **新手指引**多了一步：做完石斧石镐之后“编一个草编背包”。
  - **工具要带在身上才能用**：斧头、镐、钓竿放在仓库里时，会提示“去仓库拿出来”。做了更好的工具，旧的自动收走，不占格子。
  - 键盘：1–8 选快捷栏，B 打开背包。
- **[完成] 工具拿在手上**：斧头、镐（石 / 铜 / 铁三种颜色）、钓竿都有了手持模型，拿在右手。砍树、挖矿时跟着动作抡起、砸下、收回；钓鱼时竿伸向水面，**竿尖到浮标有一根鱼线**（等鱼时松垂，收线时绷直）。快捷栏里选中一把工具，平时也拿在手上。
- **[完成] 坐在载具里**：飞机驾驶舱里能看到人头（帽子、围巾），船尾坐着一个人、一只手扶着舵。路上遇到的别人的飞机、船，以及海盗船、空盗飞机，也都有人在里面。

## 我重玩时发现并改掉的

- **走路时腿和胳膊不动** → 加了两帧步态，和走路的上下颠动同步。岛主也有。
- **岛主像雕像一样站着** → 现在在村子附近闲逛，你走近时转身看你、冒一个对话气泡打招呼（越熟说的话越热情），说话时有“动森式”的叽里咕噜声。点他说的话也改成头顶气泡，不再是屏幕顶端的一行字。有货要交时，他会留在跑道或码头边等你。
- **正在砍的树会变成半透明** → 现在保持实心（其他挡住小人的东西照旧变透明）。
- **彼岸的位置有问题**：它几乎在家的“对面”（世界首尾相连），从那里飞回家，方向箭头会在“往东”和“往西”之间来回跳，自动测试里飞机原地转圈。挪近了（9.6 km → 7.7 km），方向不再跳。
- **天色变化会改掉飞机的手感**：飞行途中天黑或天亮时，载重带来的变慢、变笨会被重置。已修。
- 视角按钮挪到了屏幕右侧一列，钓鱼和潜水时自动隐藏，不再挡住面板。
