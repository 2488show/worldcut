# 第十二轮改动：房子真的立在岛上

起因：第十一轮的屋子是一个单独搭出来的场景。屋子周围是我垒的一圈深色"土墙"，平常视角下看起来像屋子漂在一片黑里。用户建议把房子做成像《我的世界》那样真实存在的建筑，走进去只换个视角。另外，用户更喜欢第十轮的钓鱼，要求回退。

## 1. 房子立在岛上（一体化）

- **一栋真的房子**：
  - 主岛上的房子外墙连地基 95×69，室内 89×63。原来的小屋外观只有 29×23。
  - 墙和地板直接压进岛的地形，墙是实心的，门口是开着的。
  - 屋顶是一个模型，有瓦、山墙和烟囱，颜色沿用岛上原来的屋顶色。
  - 外墙上有窗户和花箱，晚上窗户会亮。
- **走进去，而不是传送**：
  - 点房子，小人会走到门口、跨进门槛。跨进去的那一刻，屋顶消失，前墙降成矮栏（娃娃屋的剖面），镜头转过来看进屋里。
  - 走出门，房子就恢复原样。
  - 屋里的镜头锁定朝向，不能转，保证始终是从矮栏那一侧看进去。
  - 手机竖屏时镜头稍微退后，让房间放得下。
- **选址**：
  - 在村子旁边找一块平地，避开跑道、机库、通往码头的路和矿洞。门尽量朝向广场，房子可以朝四个方向。
  - 地面会整平，并铺一条从门口到广场的小路。
  - 风车、古树、沉船这类地标如果落在房子附近，会被挪到岛的另一边。
- **紧凑、温馨的五个房间**：
  - 后排：卧室（床靠墙，旁边落地灯和衣柜）、卫生间（马桶、洗手台、淋浴、一盆绿植）、厨房（灶台和料理台靠墙，冰箱靠侧墙，餐桌配两把椅子）。
  - 前排：客厅（电视对着沙发，中间是地毯和茶几，壁炉朝向沙发）和会客区（两把椅子相对，书架靠墙，书桌靠前墙，炒股机靠侧墙，角落一盆植物）。
  - 量过模型：家具原本的大小和小人是成比例的，原来显得空，是因为屋子有 150×104 那么大。所以这次只缩房间、不缩家具，没有出现"小到看不清"的问题。
- **跟着这个改动一起修的**：
  - 窗外就是真的岛，所以那圈黑墙删掉了。
  - 躺下时的低机位，看到的是真实的屋外。
  - 屋顶会在小人走到房子后面时变成半透明。
  - 小动物不会再在屋里出现。
  - 屋里点家具不会被"房子"本身抢走点击；屋外，房子前面的信箱优先于房子被点中。
- **旧存档迁移**：
  - 初始家具直接摆到新房间里对应的位置。
  - 玩家自己添的家具（大的先放）会自动找一个合法的空位；实在放不下就进家具箱。
  - 迁移前后家具总数不变，有测试锁住。

## 2. 钓鱼回退到第十轮

- 钓竿的玩法和钓鱼界面恢复成第十轮的样子：咬钩时按"提竿"，搏鱼时按住收线，鱼挣扎时松手。
- 钓上来的鱼仍然量一下尺寸，记进图鉴，飘字从"鲷鱼！"变成"鲷鱼 32 cm"，不加任何操作。
- 潜水、鱼的图鉴、鱼缸、标本都不变。
