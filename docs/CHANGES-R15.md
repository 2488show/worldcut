# 第十五轮改动（第一部分）：三个小修

用户试玩后的反馈。多层楼、小屋起步、"里面比外面大"是结构性的改动，先讨论，不在这一部分里。

## 1. 小岛升级的入口找不到

- 原因：升级在书桌上（岛务手账）。第十三轮把电脑放到了书桌上，点书桌多半点到电脑；书桌又背对镜头，不容易认出来。
- 现在在自己岛上，左上角岛名下面有一个"⌂ N 级"的小按钮，任何时候点它都打开岛务手账。条件够了可以升级时，按钮上会有一个跳动的 ↑。
- 电脑桌面上也多了一个"岛务"图标。

## 2. 电脑背对玩家

- 书桌和电脑搬到会客区的后墙边，屏幕朝着房间，和电视一样正对镜头。书架挪到了侧墙边。
- 旧存档：书桌、电脑、书架如果都还在原位，会自动对调；有一个被挪过，或者新位置被占了，就都不动。

## 3. 体力消耗太快

- 干活的体力消耗全部减半（砍树、采矿 2 → 1，铲地 4 → 2，抛竿 3 → 1.5，等等）。
- 饱腹：放着不动，原来约三分之二天就饿空，现在是一天半。干活带来的额外饥饿也减了四成。按一天两顿饭来算是够的。

## 验证

- `npm test`：20 个文件、91 个测试全部通过（新增 `tests/round15.test.ts`）。
- `tools/e2e.py`：桌面和手机各一遍，全部通过。桌面有一次帧率检查没过（软件渲染下 22 帧，门槛 25），重跑是 42 帧，判断是机器负载波动。
