# 第二轮迭代 · 改动清单

按你给的 1–7 归类。每条后面的标记：**[完成]** 做透并有测试；**[基本]** 能玩、有测试，但留了明确的简化；**[未做]** 没做，原因和后续见路线图。

验证方式不变：`npm test`（26 个测试，其中一个是无头整局：捡东西→做工具→砍树→挖石→下矿→冶炼→造飞机→接单→飞→降落→收钱→钓鱼→潜水→造船→海运，每一步断言“有反馈”）；`tools/e2e.py` 在真 Chrome 里用真实点击和按键把桌面（1280×800）和手机（390×844 触屏）各跑一遍，60 帧，控制台无报错。

**我验证不了的两件事**：音乐和音效好不好听（我只能确认“有声音、场景会切换、不报错”，听不到）；真机手感和帧率。这两件请你用耳朵和手机验收。

## 1. 反馈与音频

- **[完成] 反馈管线**：游戏层只“说发生了什么”（音效 / 物品飞向背包 / 金币飞向钱包 / 横幅 / 仪式），界面负责播放；粒子、震屏、命中停顿、挤压拉伸在引擎里。整局仍可无头测试，所以“每个操作都有反馈”是测试断言，不是口头保证。
- **[完成] 打击感**：引擎新增 900 个粒子的粒子系统（木屑、落叶、石屑、火星、烟、尘、水花、气泡、羽毛、撒花…23 套颜色）、屏幕震动、命中停顿（最后一击 0.09 s）、每个物体的挤压/拉伸与弹簧回弹。
- **[完成] 砍树的层次**：每一斧 → 挥击姿态、木屑向后飞、树冠抖落叶子、树身摇晃（越砍越厉害）、音调逐渐升高；最后一斧 → 停顿、“吱呀”、缓缓倾倒再加速、落地闷响 + 震屏 + 扬尘 + 落叶，木头弹出来飞进背包，树桩留下，过一阵“啵”地长回来。
- **[完成] 物品飞进背包 / 金币飞进钱包**：掉落物先弹出、悬停、再加速飞向背包里对应的那一格（格子会弹一下，音高逐个升高）；金币飞向钱包，数字滚动。
- **[完成] 反馈分三层**：日常（音效 + 粒子 + 轻震）；一步完成（顶部横幅 + 小撒花 + 提示音）；里程碑（全屏仪式：白闪、旋转光芒、撒花、号角，一生一次）——第一架飞机、第一艘船、第一次送货、第一次挖到金矿/水晶/月光石、第一次钓到稀有鱼、岛屿升级、炸岛。
- **[完成] 加工有过程**：工作台每件 0.8 秒、三锤（火星、木屑、进度条、锤子动画）；熔炉燃烧时模型换成点火的（炉门和烟囱口闪烁）、冒烟、溅火星、噼啪声，出炉“叮”一声，铜锭飞进背包。
- **[完成] 其余操作**：脚步声 + 扬尘、点地面的落点星光、开关面板、接单盖章、买卖、建造（一层层堆叠，每层一声敲击 + 火星）、起飞滑跑扬尘、离地“叮”、加速和翻滚的风声、触地闷响 + 震屏、靠岸水花、拒绝操作的“嘟嘟” + 红色抖动提示。没有自带声音的按钮由界面兜底补一声“嗒”。
- **[完成，待你听] 音乐**：全部程序化合成（WebAudio），零音频文件。一台生成器：短动机 + 变奏（移位、倒影、截短、高八度应答）+ 大段留白 + 慢和弦铺底 + 回声和长混响。六个场景各有调式、速度和配器——岛上（D 大调五声，54 拍）、矿洞（A 小调，低沉、少音）、水下（利底亚、闷）、飞行（F 大调 + 琶音）、航海（混合利底亚 + 浪声）、海盗（弗里吉亚属、104 拍、低音脉冲）。切换在小节线上完成，海盗例外（下一拍就切）。引擎声、浪声、风声、熔炉噼啪是跟随状态的循环。右下角 ♪ 静音。

## 2. 镜头、比例、建模

- **[完成] 比例重校**：岛上的树、岩石、设施、人物从“地形图章”（只能是锥和块）全部改为体素模型，用和战机同一套切片渲染。小人 12 高；树 17–29；小屋 25；机库 23；熔炉连烟囱 24；灯塔 46。树有真正的树冠悬在树干上。
- **[完成] 岛上的倾斜 3D 视角**：复用原型“追尾视角”的透视投影，镜头跟在小人身后，能看到海平线和远处的岛。**空格**切换倾斜 / 正俯视；**Q / E** 每次转 45°；滚轮或“远/近”缩放。挡住小人的房子和树会自动变半透明。
- **[完成] 按键重排**：空格 = 换视角（岛上、飞行中都是）；加速改到 **Shift / J**（按住鼠标照旧）；F / 回车 = 钓鱼收线。手机：底栏“俯/斜”“↶ ↷”“远/近”，飞行时“加速”“视角”。
- **[完成] 矿石一眼可辨**：颜色和形状都不同——铜是橙色圆瘤带绿锈，铁是锈红斜纹，煤是黑方块，金是浅色岩里的亮黄斑，水晶是竖立的晶簇（会闪）。色弱也能分。
- **[完成] 设施更精细、有动态**：工作台（工具墙、台钳、刨了一半的木板）、熔炉（砖纹、拱形炉门、烟囱、风箱、煤堆；点火后闪烁冒烟）、布告板（小屋顶、钉着的各色纸条）、仓库（箱子、木桶、麻袋）、小屋（木骨架、窗台花箱、瓦屋顶、烟囱）、机库（红白波纹拱顶、门灯闪烁、风向袋）、矿洞口（木框、提灯、铁轨、青苔）。树在风里轻轻摇。
- **[完成] 背包图标说明**：鼠标悬停或手指长按 0.3 秒，显示名称、稀有度、数量、单价和一句用途。面板里的图标也有悬停说明。

## 3. 三大采集系统

- **[完成] 工具规则**：砍树要斧、挖石头和矿要镐；材质（石 / 铜 / 铁）决定敲几下和能采什么（老橡树要铜斧，铁矿要铜镐，金矿水晶要铁镐）。灌木、亚麻、野花、树枝、卵石、贝壳徒手采。工具不设耐久（理由见决策 D28）。
- **[完成] 砍树**：橡树（小/中/老）、果树、白桦、松树（小/中/老）、棕榈（小/大），产木材 / 松木 / 棕榈木；过程见上；树桩再生。
- **[完成] 矿洞**：每座岛山脚一个。每层 21×21 格随机洞穴；矿种按深度分带（1–3 层石、煤、铜；4–6 层加铁、少量金、水晶；7 层以下金、水晶、月光石），乘以岛的矿藏丰度，成簇分布。黑暗里只有身边一圈亮（提灯更远）。**没暴露的矿看起来就是普通岩石，挖开旁边一格才显形**（闪光 + 提示音；稀有矿有专门的音效和提示）。岩石逐击开裂。往下的梯子藏在某块岩石下（那里有细尘落下）；第 3、6 层的梯子在硬岩后面，要铜镐 / 铁镐。到过的层可从洞口直达。岛 1 级 6 层，升级后 9 / 12 层。每 15 分钟重新长满。
- **[完成] 钓鱼**：有钓竿就能在任何岸边点水面抛竿。岸边游着黑影（看得见的鱼，大小不同），往它附近抛，它会游过来。等待（有假咬）→ 浮标猛沉后 1.2 秒内提竿 → 收线对抗：按住收线拉近鱼，但线的张力会涨；鱼一冲就得松手，否则绷断；松太久会脱钩。5 种鱼，越稀有越能挣扎。
- **[完成] 潜水**：从任何码头下潜。海底有礁石、珊瑚、海带，越往北越深越暗；氧气 45 秒（氧气瓶 80 秒），越深耗得越快，最后 10 秒逐秒报警。点鱼：游近并用鱼枪射（提前量瞄准；石斑要两枪，金枪鱼三枪，章鱼中枪会喷墨逃走）；点海底的海胆、贝壳、龙虾、珍珠贝：游过去捡。水母会蜇掉 7 秒的气。按时上浮渔获全归你；气耗尽只丢一半。
- **[完成] 各岛水域不同**：每种岛有自己的鱼种权重（环礁多珊瑚鱼、章鱼、珍珠；石峰多石斑、龙虾；赤砂多金枪鱼…），鱼是贸易商品（邻岛的求购单里有）。

## 4. 岛屿：随机生成、个性、升级

- **[完成] 地形生成**：岛 = 种子 + 等级。轮廓是随方位起伏的半径（岬角、海湾）+ 噪声毛边；内陆压成平缓的沿海平原，上面立着独立的山丘；环礁中间有潟湖；沙滩、浅滩、深水自然过渡。面积从半径 170 加到 200 / 250 / 300。**没有做侵蚀模拟，也没有用真实高程数据**（理由见决策 D33）。
- **[完成] 布局由地貌决定**：跑道选最平的低地带（东西向或南北向都可能，朝更开阔的一头起飞）；村子在跑道旁的平地；码头伸向最近的深水（四个方向之一）；矿洞在山脚、背后靠山；地标按类型落位（灯塔在最远的岬角、石峰在最高点、古树和风车在岛的另一头、沉船在沙滩上）。村里各建筑站哪一侧也随岛而变。
- **[完成] 随机差异与公平**：林木 / 矿藏 / 鱼群三项丰度各在 0.75–1.3 之间，**三项之和恒为 3**——没有全面更好的岛，只有不同的岛。
- **[完成] 炸岛重开**：在小屋里。只在造出第一架飞机或船之前可用，最多 3 次；背包保留，熔炉变回套件。两步确认，带爆炸演出和新岛的丰度说明。
- **[完成] 岛屿个性**：五座有人的岛各有生物群系、地标（灯塔 / 千年古树 / 石峰 / 沉船 / 风车）、岛主（站在自家门口，能搭话，会说自己出什么、缺什么）、特产（商店卖的）和需求。另有五座无人礁。
- **[完成] 升级**：小岛 → 大岛（600 金币 + 3 次送货）→ 群峰之岛（2200 金币 + 10 次送货）。同一颗种子放大一号：更多山、更多资源、矿洞加深 3 层。迁移：建筑和载具搬到新地形上的位置，熔炉和家具留在相对村子的原位（位置没了就挪到最近的空地，再不行回背包），植被全部重新长。演出：爆炸声、震屏、全屏仪式、镜头拉远看全岛再拉回。

## 5. 送货旅程、降落与交货

- **[完成] 距离有远有近**：邻岛离家 5.8 / 8.2 / 8.5 / 11.5 km（之前都是 ~10 km）。
- **[基本] 路上的事**：风（每半分钟变向，顺风快、侧风把你推偏，HUD 有风向箭头）；海鸟群（横穿航线，穿过去会惊散它们并借到 4 秒气流）；漂流箱（在航线两侧，绕过去能捞到金币或材料）；过客（别的岛主的飞机 / 船，靠近会摇翼 / 鸣号致意）；雨云（进去会变慢、画面变灰，绕开更快）。*简化：天气只有雨云一种；“其他玩家的载具”是模拟的。*
- **[完成] 载重影响手感**：货舱越满，巡航越慢（最多 −16%）、加速越弱（−30%）、转向越笨（−38%）。HUD 显示“轻载 / 半载：有点沉 / 满载：很笨重”。
- **[基本] 降落奖励**：接近目的地时出现“进场”仪表；按下降落那一刻，按航向和偏离跑道中线的程度打分，穿过跑道延长线上的金色光圈加分。≥80 分“完美进场” +20% 收入，≥55 分 +10%。船是“从海上正对码头、别加速”。*简化：落地本身仍是自动完成的——评的是进场，不是手动接地。保留了“永不坠机”。*
- **[完成] 收货人**：有货要到时，岛主会走到跑道边（或码头上）等。交货时他会跳一下、冒爱心、说句话，金币从他手里飞进你的钱包。

## 6. 海盗与空盗

- **[完成] 基调**：永不坠机。只出现在标了 ☠ 的航线上、只在你完成 3 单之后、只在货舱有货时，而且不是每次。
- **[完成] 预警**：先在侧后方 2.3 km 处被目击——警报声、顶部红色警告条（方位箭头、距离、“咬住”进度）、音乐转入紧张的变奏；3 秒后才开始追。
- **[完成] 应对**：它比你“重载加速”快、比你“轻载加速”慢——轻载可以直接跑掉，重载得靠急转弯（它转弯半径比你大，被你甩到身后就会丢失目标 2 秒）、钻雨云（它在雨里更慢）、或者冲到目的岛附近（岛上的了望塔会吓退它）。30 秒追不上也会放弃。逃脱：音效 + 横幅 + 撒花。
- **[完成] 代价**：贴近 2.8 秒才得手。抢走 30% 的货（装了货舱锁 15%）——停顿、震屏、炮声、木箱碎片飞向对方、飘字写明少了什么。**其中一半掉进海里成为漂流箱，可以掉头捞回来**；货量很小时（抢一件就超过 40%）整件都能捞回。剩下的照常送达，按实际数量结算。
- **[完成] 风险与回报**：求购单和出发面板标明 ☠ 等级；每级危险报酬 +28%。新手期提示写在出发面板上。
- **[基本] 联动**：三种改装（增压引擎 +12% 速度、护板让“咬住”多花一半时间、货舱锁损失减半）。*未做：反击武器、护航、被抢的货出现在别的玩家的海面上（需要联网）。*

## 7. 装扮与家具

- **[基本] 家具**：11 种，四档稀有度。普通：长椅、花坛、路灯、旗杆、野餐桌；少见：贝壳风铃、晒鱼架；稀有：金枪鱼标本、水晶灯（会发光）、金雕像；传说：月光喷泉。
- **[完成] 来源多样**：基础家具来自指引任务的奖励（砌好熔炉送花坛，造出飞机送旗杆，第一次送货送长椅和路灯）和普通材料；稀有家具要水晶、金锭、月光石（矿洞深层，带运气）、珍珠、金枪鱼（钓鱼 / 潜水）、松木和棕榈木（别的岛的特产，要贸易）。
- **[完成] 摆放**：在小屋面板里“摆出去”，点一块平整的空地放下（落地有弹跳、扬尘或星光）；可以收回。
- **[基本] 用途**：每件家具有魅力值，岛的魅力每 10 点让送货收入 +2%（上限 25%）。邻岛也求购家具（长椅、花坛、路灯）。*未做：别的玩家来送货时看到你的岛（需要联网）；家具旋转、室内、邻岛自己的摆设。*

## 自评后直接做掉的改进

试跑（脚本和手动步骤混合，共约二十局）里发现并已修的：

1. 10 分钟内 4 次全屏仪式太打断 → 熔炉、第一块金属降为横幅。
2. 低角度下房子挡住小人 → 遮挡物自动半透明。
3. 空心模型在倾斜视角下变成横条纹 → 每个体素补画侧面。
4. 矿洞口被排到机库底下 → 重写选址（避开跑道、机库、码头和村子，背后要有山）。
5. 海盗刚出现就贴脸（3 秒内咬住）→ 改为从侧后方出现，给出反应时间。
6. 海盗追不上“什么都不做”的玩家、却追得上认真逃的 → 重调速度和出现时机，并用两个测试钉住两种结局。
7. 只带两件货被抢一件 = 损失 50%，超出承诺的 20–40% → 小货量时整件可捞回。
8. 浮标下沉后 1 秒的提竿窗口在真浏览器里偏紧 → 1.2 秒。
9. 升级后家具全部回了背包 → 就近找空地重新落位。
10. 第一版存档与新世界不兼容 → 存档版本升到 v2（旧存档不迁移，直接新开）。
