# 第 19 轮：坐下来做事

用户要求：吃饭时人坐在餐厅里、玩电脑时坐在电脑前，以及类似的细节、动画和音效。讨论后用户说"按你的直觉来"。期间两条评论：后厨"做"点了没反应；浇水、施肥没有动画和音效。

## 通用的"就位动作"（src/game/act.ts，game.acts）
一套流程：人就位 → 摆姿势 → 道具出现 → 按节拍放动画和声音 → 结束时收走道具。动作的效果（吃掉的饭、做好的菜）不会因为中途打断而丢。

## 做了什么
- 吃饭：屋里会走到最近的椅子（优先靠着桌子的）坐下，盘子摆在桌上，四口，盘子变空。约 2.7 秒，走开就结束。室外离餐厅近时坐到餐厅的桌边。坐着吃饱腹多一成（D143）。附近没椅子就站着吃三口。
- 电脑：走到桌前坐下（桌下拿出一张凳子），开机声和几下键盘声后打开桌面；关掉后有关机声，人站起来。点桌面图标是键盘声。
- 做饭：点"做"有下锅声、三下翻炒、锅气，约 1.2 秒后出菜；窗口顶上写结果。材料不够时灰按钮也能点，会写缺什么（修评论里的问题）。
- 浇水：手里出现水壶并前倾，水沿这一排一块块落下，洒水声和水滴声。
- 施肥：手里是一袋肥料，抖三下，颗粒落地，沙沙声，结尾提示音。
- 钓鱼等鱼：竿在水里超过 2.5 秒，人在岸边坐下，咬钩或走开就起来。
- 坐在屋里时，挡在镜头和人之间的家具会变半透明。
- 顺带修了：走到椅子坐下的那一帧，人会变回走路姿势并站在椅子高度上。
