# 第九轮：熟练度、晨间信箱、来家里做客、温馨度奖励

你给了六个方向让我挑。这一轮做了前三个加第五个（它们互相连着：做客的人会打分，温馨度奖励和回信都走信箱）。第四个“用颜料换衣服”和第六个“照相与明信片”留到下一轮。摆放颜色保持绿 = 能放、红 = 不能放。

## 熟练度
- 五种：**伐木、采矿、渔猎（钓鱼和潜水）、种地、厨艺**，各 0–10 级。干一次活就涨一点经验（砍一下、敲一下、甩一竿、钓上一条、鱼枪射中、种下、收菜、做一道菜）。
- **每升一级，这种活省 5% 体力**，10 级省一半。另外各有自己的好处：伐木 / 采矿每级多掉一份的机会 +3%；渔猎每级鱼线绷紧慢 3%、鱼枪装填快 4%；种地每级多收一份的机会 +5%；厨艺每级多做一份的机会 +4%，吃自己做的菜多回 3% 体力。
- **5 级和 10 级各学会一样新本事**：
  - 伐木：树倒下更常掉橡果 / 斧头磨损减半
  - 采矿：敲碎的石头有时带出煤 / 镐子磨损减半
  - 渔猎：潜水的气多 10 秒 / 白天也更容易遇到月光鱼（潜水也能遇到）
  - 种地：收菜一定留下种子 / 下雨时作物熟得更快
  - 厨艺：请客时客人的好感多 +1 / 请客时岛的魅力多 +2
- 升级时有庆祝（5 级、10 级是大庆祝）。航海日志新的“熟练度”页：每种的等级、进度条、每级的好处，学会的本事会亮起来。
- 节奏：1 级要 12 点经验（砍两三棵树），10 级要 840 点，大约是几百次同一种活。数值在 `src/game/skills.ts` 的 `LEVEL_XP`。

## 晨间信箱
- 小屋门口多了一个**信箱**。有没读的信时，信箱上的小红旗竖起来，屏幕右上角也有一个带数字的“信”按钮。点信箱（或那个按钮）看信。
- 每天天亮，海鸥送来夜里来的信：
  - **感谢信**：前一天给哪位岛主送了货，第二天就收到他的感谢信，附一点他们岛上的特产。
  - **回信**：请来客吃过饭、或者请到家里坐过的人，第二天会寄信来；如果他觉得你家很温馨（4 星以上），还会寄一件小家具。
  - **闲聊**：没别的信时，隔天会有认识的岛主写信聊天，信里带一句有用的话（今天的天气、深水的鲨鱼、请客的好处……），有时附几颗种子。
  - **温馨度评定**：每周一次（见下）。
  - **第一天**：邮差海鸥的自我介绍，附三颗浆果。
  - **联机**：别的玩家给你送了货，会留一张纸条。以后“好友偷菜留纸条”也从这里送（接口是 `mail.post()`）。
- 信是一张横线信纸，附带的东西点“收下”进背包（装不下会提示），最多留 30 封。

## 岛民来家里做客
- 来送货的人等在门口时，和他说话，除了请吃饭，多了一个“**请到家里坐坐**”。两人进屋，在会客区的两把椅子上对坐（没有椅子就站着），镜头拉近、上下黑边，用动森腔聊六句：说说外面的天气、他最喜欢你家哪件家具、还缺什么，最后**给你家打 1–5 星**。
- 星级按温馨度算：家具的魅力加上每间房配齐的奖励。初始家具是 3 星；添一个浴缸、书架、两盆盆栽、两盏落地灯和一块地毯就到 4 星；5 星要摆满。
- 好处：好感 +1，3 星以上岛的魅力 +（星数 − 2），第二天收到回信。他自己出门走回船上，你留在屋里。

## 温馨度奖励
- 从第 8 天起每周一次，信箱里来一封“海岛温馨协会”的评定（像动森的 HHA）：本周几星、温馨度多少、还可以添什么。
- 奖品：3 星 120 金币；4 星 200 金币 + 一件家具（浴缸、沙发、书架、壁炉轮着来）；5 星 300 金币 + 奖杯（有了以后换成水晶灯）。第一次到某个星级会特别说一句。

## 修了什么、顺手改的
- 手机上那个“信”按钮出现后，菜单按钮的位置变了；端到端测试改成按标题找按钮。
- 点建筑时，偶尔有猫或蝴蝶正好走到前面把点击“抢走”。这本来就是游戏里该有的事，测试改成没打开就再点一次。
- 请客人进屋坐下时，不再冒出“歇一会儿”；和来客说过话后，“点一下和他说话”的提示马上消失。
